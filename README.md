# Shiv Babu — QA Automation Portfolio

## How to use
1. Open `index.html` in a browser to preview the portfolio.
2. To publish it for free, create a GitHub repository named `<your-username>.github.io`.
3. Upload `index.html` and `style.css`.
4. In GitHub: Settings → Pages → Deploy from branch → select `main` → `/ (root)` → Save.
5. Your portfolio will be available at your GitHub Pages URL.

## Before publishing
- Replace the `SB` avatar with your professional photo if desired.
- Add GitHub profile URL when ready.
- Add links to public automation projects/test repositories.
- Add your actual self-healing tool/framework name if you want to claim a specific implementation.
